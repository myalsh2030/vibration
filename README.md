# الاهتزازات والاتزان — المنصة النظرية

منصة تدريبية تفاعلية لمقرر **الاهتزازات والاتزان (264 مصيم)**، تخصص **تقنية الصيانة الميكانيكية** — دبلوم الكليات التقنية.

**الرابط**: <https://myalsh2030.github.io/vibration/>
**المسار العملي**: [معمل الاهتزازات والاتزان](https://myalsh2030.github.io/vibration-lab/)

## ما فيها

٥ وحدات · ١٧ درسًا · ١١٣ سؤالًا · ١٣ محاكيًا · مسرد مصوّر بـ٩٨ مدخلًا و٤٠ شكلًا.

| الوحدة | المحتوى |
|---|---|
| عالم الاهتزاز | ما الاهتزاز، الصيانة التنبؤية، التردد و RPM↔Hz، السعة والطور |
| مبادئ الاهتزاز | الحر والجبري والتخميد، درجة الحرية، الرنين والسرعات الحرجة، الكميات الثلاث |
| أجهزة القياس | اللواقط الثلاثة، نقطة القياس والتثبيت، محلل الاهتزازات والطيف |
| المراقبة والتشخيص | أنظمة المراقبة، قراءة الطيف، بصمات الأعطال ومعيار ISO |
| الاتزان | القوة الطاردة، الاستاتيكي والديناميكي، مستوى ومستويان، الترددية |

## التقنية

موقع ثابت **بلا أدوات بناء**: HTML + ES Modules خام، يعمل **دون اتصال** بعد التحميل الأول (PWA).
التخزين محلي بالكامل (`localStorage`) — لا حسابات ولا خادم ولا بيانات تغادر جهاز المتدرب.

محرّك الفيزياء (`js/sims/vibkit.js` و`vibstd.js` و`balancekit.js`) يولّد كل رقم يراه المتدرب من
نموذج عطل حقيقي: توليف الموجة، تحويل فورييه، التكامل الترددي، الطور، كشف المغلّف، ومعايير ISO.

## الفحوص

```bash
node tools/verify-physics.mjs                 # فحص فيزيائي عددي (85 فحصًا)
node tools/validate.mjs                       # بنية المحتوى
node tools/validate-course.mjs --sibling ../../"Vibration and Balancing Lab"/website
node tools/length-audit.mjs                   # تسريب الطول في الخيارات
node tools/sync-assets.mjs --write            # مزامنة قائمة الكاش في sw.js
node tools/serve.mjs . 8123                   # تصفّح محلي
```
